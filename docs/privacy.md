# Privacy Policy

**Effective date:** 2026-10-05

How-To-Chat is a Chrome extension that reads your prompt before you send it on chatgpt.com and flags when the way it's phrased might get you an agreeable answer instead of an honest one.

## What data this extension collects

None. How-To-Chat does not collect, store, or transmit any data, anywhere.

- It does not make network requests of any kind.
- It does not use `chrome.storage`, cookies, or any other persistence.
- It does not use analytics, crash reporting, or telemetry.
- It does not create accounts or require sign-in.

## What it reads, and where that goes

The extension reads the text in the chatgpt.com chat input box as you type, so it can check it against a small set of phrasing patterns on your device. That text is processed entirely in memory, inside your browser, and discarded immediately after each check. It is never sent anywhere, including to the extension's own developer.

## Permissions

The extension only runs on `chatgpt.com`. It requests no permissions beyond the ability to read and display content on that page, which it needs to watch the chat input and show a badge next to it. It never modifies what you type and never blocks you from sending a message.

## Changes to this policy

If this policy changes, the updated version will be posted at this same URL with a new effective date.
